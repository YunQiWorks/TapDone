# 内置 Lucide 图标

选取 48 个常用操作图标，六类各八个，内置离线可用。

来源：https://github.com/lucide-icons/lucide

固定提交：`6489e9e4cbbd895e19c484cef3509dfeb144e5e9`。遵循上游 ISC 及 Feather 衍生图标的 MIT 许可，完整原文随应用打包为 `Lucide-LICENSE.txt`。唯一资源转换是将 SVG 的 currentColor 替换为黑色，作为原生模板图标使用。

- 常用：闪电（zap）、收藏（star）、喜欢（heart）、标记（flag）、书签（bookmark）、提醒（bell）、时钟（clock）、完成（circle-check）
- 开发：终端（terminal）、代码（code）、脚本（braces）、调试（bug）、构建（hammer）、分支（git-branch）、打包（package）、工作流（workflow）
- 文件：文件夹（folder）、打开文件夹（folder-open）、文件（file）、文档（file-text）、归档（archive）、剪贴板（clipboard）、下载（download）、上传（upload）
- 网络：网站（globe）、链接（link）、服务器（server）、数据库（database）、云端（cloud）、网络（wifi）、连接（network）、发送（send）
- 工具：设置（settings）、工具（wrench）、搜索（search）、显示器（monitor）、截图（camera）、图片（image）、裁剪（scissors）、锁定（lock）
- 效率：执行（play）、暂停（pause）、刷新（refresh-cw）、日历（calendar）、清单（list-checks）、统计（chart-column）、启动（rocket）、休息（coffee）
