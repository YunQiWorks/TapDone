# 任务展示配置

执行参数留在 action，展示参数使用可选的 presentation；旧任务无需迁移。

```json
"presentation": {
  "iconAssetID": "由图片导入得到的 64 位小写十六进制内容摘要",
  "activityTitle": "构建发布包",
  "activityEnabled": true
}
```

在设置中编辑任务，选择“导入图片…”，或“恢复默认图标”。Dock、设置任务列表、菜单栏共用解析逻辑。PNG/JPEG 限制 8 MB、1600 万像素及单边 8192 像素；导入时按方向缩小为最长边 512 像素 PNG，去除原图元数据，按内容摘要去重存储。显示使用固定 256 像素缓存，悬浮放大不重新解码。

资源位于 `~/Library/Application Support/SideTap/Resources/Icons/<iconAssetID>.png`，图标引用只接受内容摘要，不接受路径、URL 或可执行内容。缺失资源回退到原来的应用/文件图标或系统符号。分享 JSON 时还需一起复制对应图片资源，当前没有资源打包导入功能。

CLI 导出保留 presentation；AI 更新任务时省略它会保留现有配置，传入 `{}` 清除展示覆盖。取消任务编辑可能留下已导入但尚未引用的资源，当前不自动清理，避免误删历史运行使用的图片。

activityTitle、activityEnabled 已用于设置中的“活动”列表，编辑任务时可设置标题或隐藏该任务的活动。使用运行开始时冻结的展示配置，修改不追溯改变历史活动；隐藏不影响执行、运行记录或安全校验。未知展示字段和无效引用会被拒绝。

## 统一运行摘要

Core 的 `RunActivity` 是版本 1 的只读、可编码数据模型；`RunActivityCenter.$activities` 合并统一执行入口和流程调度器的状态。设置“活动”是首个消费者，未来灵动岛等原生界面可订阅同一数据源，无需改动执行器。

- 稳定身份为 `source:runID`，另有 definitionID、标题、符号/图片资源引用、起止时间和状态。
- 状态区分运行、远程等待、待复核、暂停及各种结束结果。按未结束优先、开始时间倒序排列。
- 流程摘要包含完成节点数/总数，只统计成功任务与批准节点；普通任务无百分比，不根据时间虚构进度。
- 能力区分查看日志、停止本地进程、停止远程跟踪、继续流程、人工复核。能力仅供显示；实际操作仍调用协调器/流程调度器并重新校验，不能通过摘要自行授权。
- 流程子任务包含 parentWorkflowRunID；每次任务状态变更都会更新列表，历史恢复也使用相同入口。
- 摘要不携带命令、环境、输入输出、日志路径或适配器返回消息，避免未来紧凑界面默认显示业务敏感内容。需要详细信息时转到运行记录或流程页面。

目前没有灵动岛窗口；流程复核从活动列表进入流程页，由原有复核界面收集理由、校验产物摘要并记录收据。远程“停止跟踪”不承诺取消服务器作业。


## 内置图标选择

默认图库为精选的 [48 个 Lucide 图标](lucide-icons.md)，按常用、开发、文件、网络、工具、效率六类组织。资源随应用离线打包，支持中文名称、分类与英文 ID 搜索，选中后即时预览。Dock、任务列表、菜单栏和活动列表共用图标解析；Dock 使用固定 256 像素缓存绘制主题强调色底板与白色图形，悬浮时不重新解码。

任务 JSON 使用 `presentation.builtinIconID` 引用，例如 `"terminal"`、`"package"`、`"server"`；只接受内置目录中的 ID，未知值拒绝导入。CLI 导出保留该字段，AI 可直接通过 Schema 查询全部可用值。图标属于展示配置，不改变任务执行。RunActivity 摘要同样携带 builtinIconID。

“系统图标”页仍提供六组 SF Symbols，仅显示当前系统提供的符号。选中设置 `presentation.useSymbol: true` 并清除自定义图片与 Lucide 覆盖，应用与文件任务也能使用所选符号。SF Symbols 是系统资源，不属于此次内置的开源图标。

显示优先级为导入图片、Lucide 内置图标、显式系统符号、原生应用/文件图标、原有符号回退。恢复默认同时清除前三种覆盖，保留活动标题和活动显示偏好。旧任务无需迁移。

完整 Lucide/Feather 许可证已作为应用资源 `Lucide-LICENSE.txt` 打包。当前没有接入 Phosphor 或 Tabler。
