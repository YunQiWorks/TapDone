# 上下游流程与复核模型

已实现流程模型、快照预检、输入映射、串行调度和人工复核。设置中的“流程”页可导入、执行和查看节点状态；CLI 的 validate 仍然只校验，不保存或执行。

## 定义与校验

流程独立于任务库文件，使用 schemaVersion 1，包含 id、name 和 nodes。参考 [Schema](workflow.schema.json)和 [打包复核示例](../examples/workflow-build-review.json)。

```bash
tapdone workflow validate --file examples/workflow-build-review.json
```

该命令从当前本地任务库解析 taskID，校验后返回节点顺序与复核节点，不保存、不执行。示例引用的 build.remote、publish.artifact 需要先配置成实际任务。

节点分为 task 和 review。task 引用现有任务；review 必须声明上游依赖，不允许填写 taskID 或 inputBindings。节点 ID 必须唯一，引用必须存在，不能依赖自身或形成循环。最多 128 个节点，定义文件不超过 1 MB；未知字段和 null 字段拒绝处理，可选字段应省略。

工作流的 task 节点当前只接受协议 v2 的 external，必须声明 inputContract 和 outputContract。可以引用已配置的远程异步任务。普通命令退出码和系统打开请求不是充分的业务证据，因此暂不允许它们直接充当流程任务。

## 快照与输入映射

WorkflowPlan 冻结本次流程定义、引用任务配置和任务库 revision。之后编辑原任务不会改变该计划。外部脚本内容、服务端状态或路径指向的文件内容不在配置快照内；本阶段不提供脚本版本封存。

inputBindings 将直接依赖节点的输出对象属性写入当前任务 input 的顶层字段。path 是明确的对象属性数组；空数组表示整个输出。不解析代码、不插值 shell 文本、不自动执行产物地址。

预检要求源属性和目标属性都在输入输出约束中声明，类型相同（允许 integer 传给 number）。执行前解析映射时还会再次校验上游值，检查真实属性是否存在，并校验最终输入。数值范围和字符串长度等约束在此时校验，类型匹配本身不等于数据有效。

调度器只向映射器提供本次流程中已成功、通过协议与约束校验的节点输出；每次接受完成回调时，核对子运行定义与冻结配置，并确认最终结果已经持久化。WorkflowPlan.action 本身只负责映射与校验。

## 复核安全边界

复核上下文包含流程运行 ID、复核节点 ID、上游运行 ID 和对应结构化产物。排序后的上下文 JSON 计算 SHA-256 摘要。

用户提交决定时必须带上界面显示内容的 expectedDigest，并提供复核人和理由。上下文变化会拒绝决定。批准收据记录该摘要、时间、决定与理由；authorizes 只接受相同流程运行、节点与产物上下文的批准收据。驳回收据永远不授权下游。

上游重新执行会产生新的运行 ID，即使产物相同也不能复用旧复核。复核只约束明确依赖它的下游节点；定义中没有依赖复核的其他分支，不会自动被它阻挡。

这是本机复核记录，不是身份认证、数字签名或多用户权限系统。设置“流程”页已提供复核界面，显示上游运行 ID 和结构化产物，必须填写理由才能批准或驳回；当前 CLI 不提供批准或执行命令。

## 执行与重启

1. 先添加符合 v2 和输入输出约束要求的 external 任务，再在设置“流程”页导入流程 JSON。导入不执行。
2. 点击“执行”时重新预检并冻结计划。同一个流程已有未结束运行时拒绝重复启动。
3. 首版按拓扑顺序串行执行一个就绪任务，不并行执行独立分支。任务与普通任务共用执行器、历史和重复启动保护。
4. 只有通过身份、持久化结果和输出约束校验的成功节点才能解锁下游。上游失败/中断/超时则结束流程，不自动重试。
5. 到达复核节点后显示“等待复核”，批准且收据上下文仍一致才继续，驳回结束流程。
6. 重启后未结束流程先暂停；点击“继续流程”时核对冻结计划及已有子运行。远程子任务可继续查询，本机中断任务不自动重跑。
7. 节点启动前先保存 starting 状态，再创建子运行并保存其 ID。若在这个窗口崩溃，不能确认是否已经启动，恢复时要求人工检查，不重复执行。
8. “停止流程”阻止后续节点并请求停止当前子运行；对远程作业只停止跟踪，不能保证服务端已取消。

流程定义保存在 `Workflows/Definitions/`，运行快照保存在 `Workflows/Runs/`；目录 0700、文件 0600，原子替换。重新导入同 ID 定义会更新以后运行使用的定义，不修改正在运行的计划。流程节点的任务记录仍在 `Runs/`，可从流程页查看子运行日志。

保存失败时暂停调度并显示错误；复核决定未保存成功不会解锁下游。等待远程或复核的流程允许应用升级，升级退出时暂停；本机正在执行的任务纳入更新等待计数。

目前流程入口在设置面板，尚未接到 Dock 或菜单栏。可视化流程编辑器、并行分支、节点重试、远程取消、脚本内容快照和多用户审批不在本阶段实现中。
