# 独立任务运行浮窗

任务启动后，默认在鼠标所在屏幕的顶部居中、可用区域顶部下移 64 点显示独立浮窗，无需先打开管理界面。浮窗不激活 TapDone，也不抢键盘焦点；首次出现后保持在同一屏幕，显示器变化时重新适配。可跨桌面和全屏空间显示。

## 展示规则

- 运行中、等待远程结果、流程暂停、待复核：保持显示。
- 成功或停止：显示约 5 秒后收起；没有剩余条目时自动隐藏浮窗。
- 失败、超时、中断：保留提示，直到手动隐藏。
- 单个运行只显示任务卡片，窗口高度随卡片内容适配，不显示外层标题和底部说明。
- 多个运行显示带数量、查看全部和统一隐藏入口的列表面板，内容过多时滚动；流程子任务并入父流程，避免重复浮窗。
- 启动时不会重新弹出历史成功/失败记录；仍未结束的作业和暂停流程可以显示。
- 遵循任务定义快照的 activityEnabled 偏好；标题和图标复用统一运行摘要和任务定义快照。
- 流程显示当前节点、完成节点数；普通任务仅显示状态和累计经过时间，不虚构实时百分比。耗时包含等待时间。

浮窗只显示安全的状态说明与流程节点名称，不自动展示外部脚本返回内容、命令、环境变量或详细错误文本。打开详情或日志后再查看完整信息。打开应用/网址/文件的成功仅表示系统接受请求。

## 交互

- “查看详情”打开对应任务；“查看流程”定位并展开对应流程运行。
- “前往复核”定位待复核流程并打开原有复核面板；仍需填写理由，通过真实摘要校验后才能批准。
- 编辑工作区存在未保存草稿时，先确认是否放弃，避免浮窗导航覆盖草稿。
- “日志”读取对应运行记录并打开日志；“停止”走原有执行协调器，“停止流程”走原有流程调度器。
- “停止跟踪”不代表取消服务器作业。
- 单条关闭或顶部关闭只隐藏当前运行，不会停止任务；同一次运行的后续状态不会强制重新弹出。
- 新运行仍会自动显示。菜单栏“任务运行状态…”可重新显示当前运行及本次会话尚未过期的错误记录；没有条目时提供活动页入口。

退出应用时关闭浮窗订阅和自动收起计时，然后按原有逻辑处理正在执行的任务。

## 开发预览

Debug 的“效果预览”已复用同一浮窗卡片。选择运行场景后点“弹出运行浮窗”，可显示真正独立的预览窗口；模拟播放会更新它。每次切换场景重置预览浮窗的关闭与自动收起状态，以便重复观察。预览模型直接持有窗口，在场景快照生成后同步显示，不依赖页面刷新。默认保持完成状态可见；勾选“预览完成后自动收起（5 秒）”可模拟正式任务的自动收起规则。

预览使用独立 ActivityOverlayModel，不连接真实活动中心；停止、日志、复核和详情按钮都是模拟回调。离开效果预览页会关闭预览浮窗，不影响真实浮窗或任务。


## 浮窗位置设置

在“设置 → 运行浮窗”选择顶部居中、左上角、右上角、底部居中、左下角、右下角。上下边距可在 16–200 点之间调整，默认 64 点；边距从屏幕可用区域计算，避开系统菜单栏和 Dock，空间不足时自动缩小边距和滚动区域。

浮窗宽度默认 420 点，受屏幕可用宽度约束。设置即时生效并保存在 UserDefaults；恢复默认位置会回到顶部居中和 64 点。开发效果预览使用同一份位置偏好，可直接调整并观察弹出的预览浮窗。

设置中的“显示浮窗”可手动唤出窗口，没有运行条目时也会显示空状态。浮窗使用 statusBar 窗口层级，并保持不抢键盘焦点。
