# 开发版效果预览

使用 Xcode 打开 `TapDone.xcodeproj`，在 `TapDone` scheme 的 Run 配置选择 **Debug**。自行启动开发版后，左侧底部可进入“效果预览”。Release 安装包不提供入口，也不编译预览场景和模拟播放逻辑。

## 使用

1. 从“场景”下拉框选择 27 种状态之一。
2. 点击“模拟播放”观察一组状态依次切换；“暂停”停在当前状态，“重置”回到该组初始状态。每步间隔约 1.5 秒，切换场景或离开页面立即停止播放。
3. 在右上角切换跟随系统、浅色或深色，可手动调整主窗口宽度检查换行与布局。
4. “等待人工复核”可打开正式复核面板，填写理由后批准或驳回；只更新预览内存。打开复核时暂停自动播放。
5. 查看日志、结果、停止、继续等按钮均为模拟回调，不打开系统文件或执行程序。

## 场景

- 普通任务：尚未运行、运行中、成功、失败、超时、停止、中断。
- 异步作业：提交中、等待远程结果、远程完成、查询中断。
- 上下游流程：启动、部分完成、失败阻断下游、暂停、完成、停止。
- 人工复核：待复核、批准、驳回。
- 图标与边界：长名称、长返回内容、48 个 Lucide 图标总览、自定义图片外观、图片缺失回退、空白、存储错误。

自定义图片场景使用应用内置图片在内存中模拟外观，不触发图片导入或资源写入。流程使用专用展示快照，不是可导入或可执行的工作流定义。

## 隔离与复用

`ExecutionPreviewView.swift` 整个文件受 `#if DEBUG` 保护，导航枚举、入口和路由同样只在 Debug 生效。预览不创建 AppStore、TaskRepository、TaskExecutionCoordinator 或 WorkflowRunner，不读写真实任务、运行记录或复核收据；仅图标展示会使用已有的只读资源解析。

正式任务详情和预览共用 `TaskRunSummaryCard`，活动列表共用 `RunActivityRow`，流程节点共用 `WorkflowNodeStatusView`，复核共用 `WorkflowReviewView`。它们接收数据和回调；真实执行授权仍在应用原有协调器中。

此页面用于人工检查 UI 状态和交互，不代表真实脚本、网络请求或执行链路已经验收。


“弹出运行浮窗”可以在管理窗口之外查看同一场景；从“尚未运行”点击时会自动切到“运行中”。预览模型持有独立窗口，每次场景快照生成后直接同步，模拟播放也会同步更新；离开页面自动关闭。静态预览默认保持显示，勾选“预览完成后自动收起（5 秒）”可观察成功和停止后的自动收起效果。该窗口不连接真实活动中心，详见 [独立任务运行浮窗](activity-overlay.md)。
