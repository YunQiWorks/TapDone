即达 · TapDone 0.3.0

- 全新管理界面：左侧导航与分类任务树，右侧查看任务详情、执行与编辑；支持搜索、Dock/最近使用筛选及可调整窗口布局。
- 任务详情集中展示图标、执行按钮、Dock 开关与最近结果；高级配置默认折叠，编辑草稿切换时提示确认。
- 内置 48 个精选 Lucide 图标，支持分类搜索、自定义 PNG/JPEG 图片和原生系统图标。
- 统一任务运行记录、状态与展示摘要；新增严格 v2 返回协议和输入输出约束。
- 支持外部异步作业提交、持久化查询及重启恢复，避免盲目重新提交。
- 新增上下游流程、输入映射与人工复核，复核通过后才解锁下游；流程重启后暂停等待确认。
- 工程、CLI 与 AI Skill 名称统一为 TapDone；保留旧 CLI 入口、数据目录、应用身份和协议环境变量兼容。

外部脚本与任务配置仍可独立更新，无需重新编译应用。远程任务“停止跟踪”不代表取消服务器作业。灵动岛窗口尚未提供。
