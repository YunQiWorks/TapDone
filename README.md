# 即达 · TapDone

**一键即达，一键完成。**

把常用操作变成一个按钮，点一下就执行。

TapDone 是一款 macOS 快捷操作工具。把打开网站、访问文件夹、运行脚本等常用操作放进自己的快捷栏，鼠标移到屏幕边缘，停留片刻即可唤出，点击按钮执行任务。

让重复操作少几个步骤，让常用工具随手可达。

## 可以用来做什么

- **直达常用内容**：打开工作网站、应用、文件或项目目录。
- **一键运行脚本**：把已有的打包、部署、文件处理等脚本接成按钮。
- **整理工作入口**：按工作、开发、生活等分类管理任务，只把最常用的几个放进快捷栏。
- **让 AI 帮你添加操作**：描述想做的事，让支持本机操作的 AI 编写脚本、添加任务，以后点一下就能再次执行。

脚本任务需要先配置对应脚本及运行环境。TapDone 当前支持单个任务执行，多步骤流程可以由外部脚本实现。

## 从屏幕边缘，点一下

平时收起，需要时出现。你可以选择屏幕上、下、左、右边缘或四个角，调整触发范围和停留时间，让快捷栏适应自己的使用习惯。

快捷栏采用 Dock 风格，悬停时放大图标并显示任务名称。点击任务或移开鼠标后自动收起。菜单栏中也能按分类找到并执行全部任务。

## 开始使用

支持 **macOS 13 及以上版本**。

1. 从 [Releases](https://github.com/YunQiWorks/TapDone/releases) 下载已发布的安装包，解压后将应用放进“应用程序”。如果尚无安装包，开发者可参照 [开发说明](docs/development.md)从源码构建。
2. 打开应用，在设置的“任务”页添加分类和任务。
3. 为常用任务勾选“显示在 Dock”。
4. 在“边缘唤出”中选择位置和停留时间，然后将鼠标移到对应边缘试用。

目前采用免费发行方式，未经过 Apple 公证。首次打开若被 macOS 拦截，确认下载来源后，可在“系统设置 → 隐私与安全性”中允许打开。

## 让 AI 把想法变成按钮

例如，你可以告诉 AI：

> 帮我添加一个“打包项目”按钮，执行我项目里现有的打包脚本，并显示在快捷栏中。

在“设置 → AI 接入”复制 CLI 路径和接入说明，交给支持本机终端操作的 AI。它可以查询、添加和修改任务，应用会自动同步；也可以通过设置导入任务文件。

新增功能可以交给外部脚本实现。之后修改脚本，下次点击就会使用新内容，无需重新编译软件。**添加任务不会立即执行，执行由你点击触发。**

## 任务与更新

任务按“分类 → 子任务”管理，支持编辑、移动和排序。快捷栏只展示你选中的任务；运行中的脚本可以在“运行记录”中查看状态、日志或停止。

任务配置和外部脚本保存在本机。软件升级会更新应用和内置工具，保留独立的任务配置与脚本。发布者配置好更新源后，可从菜单栏或设置中检查更新并确认安装。
